New in v2 · Guidance

Do / Don't Guidance

A reusable annotation block, matching the glossary entry template, for documenting how each surface should and should not be used.

<!-- Do / Don't annotation blocks -->
✓Use one primary button per surface so the main action is unmistakable.
×Don't stack multiple primary buttons; demote others to .secondary.
✓Pair every status colour with a text label (WCAG 1.4.1).
×Don't rely on colour alone to communicate state.
✓Show dates to operators as DD-MM-YYYY.
×Don't surface raw YYYY-MM-DD machine formats in the UI.
