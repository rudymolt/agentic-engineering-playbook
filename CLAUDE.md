# AI Engineering Playbook — public repository contract

Read [`AGENTS.md`](AGENTS.md) and [`v0.5/AGENT-DIGEST.md`](v0.5/AGENT-DIGEST.md) before changing this repository. A non-trivial process change begins at stage 01 alignment and is specified and sliced before implementation.

The live edition is `v0.5/`. Preserve user work, update the changelog with a *Why* line, regenerate the edition and delivery manifests, and run the canonical verifier. New public files must pass privacy and attribution review. Keep application projects on a pinned stable release checkout while this repository's development branch moves.

Time checkpoints and verification reserves report progress and plan capacity; they do not require extension approval while progress continues. Continue necessary reversible in-scope fixes and fresh verification until a real scope, authority, safety, quota, or no-progress boundary is reached.
