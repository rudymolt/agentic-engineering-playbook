# Complete Matt bundle — build contract

## Acceptance

- Package all twenty current registry Matt skills at the existing pin, including
  complete references, host metadata and notices. Preserve `pr`'s nested
  `metadata.credits` and `CREDITS.md`; `show-me` is attribution, not a dependency.
- Validate the reviewed metadata subset, rejecting malformed, duplicate or
  unsupported mapping structures without activating files.
- Declare source-observed dependencies for `implement`, `triage`,
  `improve-codebase-architecture`, `wayfinder` and `grill-me`.
- A disposable consumer provisions the complete inventory, repairs an absent
  managed skill, preserves committed retained customizations and unrelated
  content, and leaves incompatible embedded review refused with its fallback.
- Installation leaves route selection and invocation authority unchanged.

## Agreed verification seams

Use the existing public `generate-skill-bundle.py` and `provision-skills.py`
commands with pinned-source/disposable release fixtures. Exercise preview,
install, check, retain and recovery through their JSON and filesystem effects.
The exported recovery launcher and Conductor setup command are existing
integration seams; their fixture checks cover packaging and discovery aliases.
Actual host discovery and behavior remain unqualified by these local tests.

Red before green: expand the complete-inventory provisioning regression first,
then add adversarial attribution cases at the same CLI seam. Reuse the existing
preservation, recovery and compatibility tests rather than duplicate them.
