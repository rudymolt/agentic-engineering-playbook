# Complete Matt bundle — alignment

The approved S2 slice makes every current Matt skill in the playbook registry
replayable through the existing project provisioner. The human confirmed
continuation on 2026-11-01 after the inventory and diagnosis were recorded.
The current bundle includes eleven of twenty registered skills; the pinned
`pr` definition also exposes an unsupported nested attribution mapping.

Keep the reviewed v1.3.1 source and its complete directories unchanged. Extend
the existing bundle and metadata validation, preserving invocation controls,
attribution, dependencies, customizations and stage-owned review fallbacks.
Installation is distinct from runtime discovery and invocation qualification.

This slice changes public packaging only. Other packages, private personal
definitions, consumer adoption and actual Cloud lifecycle qualification belong
to later slices. No Cloud sessions or settings changes are needed here.

Follow ADR [0002](../../docs/adr/0002-release-bundled-project-skills.md).
Monthly upstream review and deliberate migrations recheck metadata, dependency
closure and host compatibility while preserving customizations; startup keeps
replaying the approved pin.
