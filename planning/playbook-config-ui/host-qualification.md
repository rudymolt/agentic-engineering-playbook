## Evidence envelope

Before either walkthrough, record privately: candidate SHA, edition/tag used for adoption, host/runner version, date, requested and runtime-resolved model and effort, session/thread identifiers, permission mode, tool-use and elapsed-time evidence. Coordinator identity comes from authoritative host metadata, not the model's self-description. Redact credentials, account details, billing facts, machine paths and project execution records from any public summary.

Use disposable consumer projects and the existing bootstrap/upgrade preview gates. Preserve an independent before-copy of execution state and approvals for exact byte comparison. No experimental candidate skill invocation or paid model comparison is allowed. Any billable qualification launch beyond normal read-only configuration discovery needs its own human-scoped decision.
