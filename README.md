# AI Engineering Playbook

**Current release:** V0.5.0.

The public playbook is [V0.5](v0.5/README.md). Start with its [agent digest](v0.5/AGENT-DIGEST.md), or open the [interactive guide](v0.5/index.html).

This repository begins with V0.5.0. It contains no earlier edition trees or private development history. New projects use the [bootstrap skill](v0.5/skills/ai-playbook-bootstrap-project/SKILL.md) from a pinned release checkout. Existing projects using the historical private V0.4.2 edition should follow the tested transition guide before changing their recorded path. A project still on V0.3 first uses its existing private migration bridge.

Stable consumers should pin a release tag in a separate checkout. Development happens on `main` and feature branches. See [contributing and release guidance](v0.5/MAINTENANCE.md).
