Sample Athletics UI Kitchen Sink

A single-file visual glossary for Sample Athletics operations app. The structure follows broad kitchen-sink catalogues: foundations first, then elements, collections, and modules. The visuals are copied from the current Sample Athletics Tailwind tokens and shared UI patterns, not from an external theme.
