# Design glossary — index

## Components

* [announcement-banner](components/announcement-banner.md) — An `announcement-banner` is a full-width notice with an icon, message, and optional action. [#feedback](../sample-athletics-ui-kitchen-sink.html#feedback)
* [athlete-name-chip](components/athlete-name-chip.md) — An `athlete-name-chip` is a rounded pill showing one athlete's name, colour-coded by sex. [#buttons](../sample-athletics-ui-kitchen-sink.html#buttons)
* [avatar](components/avatar.md) — An `avatar` is a small round (or square) badge of an athlete's/person's initials. [#patterns](../sample-athletics-ui-kitchen-sink.html#patterns)
* [banded-rows](components/banded-rows.md) — A `banded-rows` treatment is the zebra-striping + hover applied to table and list rows so each row reads as a distinct band. [#tables](../sample-athletics-ui-kitchen-sink.html#tables)
* [breadcrumb](components/breadcrumb.md) — A `breadcrumb` is a single-line trail of ancestor links ending in the current page. [#navigation](../sample-athletics-ui-kitchen-sink.html#navigation)
* [column-filter-menu](components/column-filter-menu.md) — A `column-filter-menu` is a table-header popover used to sort one column and choose visible values for that column. [#tables](../sample-athletics-ui-kitchen-sink.html#tables)
* [disclosure-row](components/disclosure-row.md) — A `disclosure-row` is a `<details>` row that expands to reveal inline controls, with a rotating chevron. [#patterns](../sample-athletics-ui-kitchen-sink.html#patterns)
* [do-dont-guide](components/do-dont-guide.md) — A `do-dont-guide` is a paired set of green "do" and red "don't" rule blocks. [#patterns](../sample-athletics-ui-kitchen-sink.html#patterns)
* [entry-status-chip](components/entry-status-chip.md) — An `entry-status-chip` shows an athlete's competition-entry state — Confirmed (green) or Planned (neutral) — as a compact chip beside the name on the Results table. [#buttons](../sample-athletics-ui-kitchen-sink.html#buttons)
* [event-prep-tile](components/event-prep-tile.md) — An `event-prep-tile` is a small stacked tile showing a preparation milestone time and its label. [#containers](../sample-athletics-ui-kitchen-sink.html#containers)
* [medal-icon](components/medal-icon.md) — A `medal-icon` is a small ribboned-disc icon whose colour encodes a podium place — gold (1st), silver (2nd), bronze (3rd). [#buttons](../sample-athletics-ui-kitchen-sink.html#buttons)
* [place-badge](components/place-badge.md) — A `place-badge` is a small pill showing a non-medal finishing place (4th–8th). [#buttons](../sample-athletics-ui-kitchen-sink.html#buttons)
* [place-num](components/place-num.md) — A `place-num` is the plain finishing-place number (4th and below) shown in the daily Results table, paired with `medal-icon`s for 1st–3rd. [#buttons](../sample-athletics-ui-kitchen-sink.html#buttons)
* [placing-tile](components/placing-tile.md) — A `placing-tile` is one cell in the 1st–8th medal-count strip showing a place and the team's count at that place. [#containers](../sample-athletics-ui-kitchen-sink.html#containers)
* [sex-indicator](components/sex-indicator.md) — A `sex-indicator` shows an athlete's sex as a gender symbol plus label — `♂ Male` (blue) / `♀ Female` (pink). [#buttons](../sample-athletics-ui-kitchen-sink.html#buttons)
* [standard-table-controls](components/standard-table-controls.md) — `standard-table-controls` are the reusable mission-control table controls for sorting, column filtering, active filter chips, and table reset. [#tables](../sample-athletics-ui-kitchen-sink.html#tables)
* [status-legend](components/status-legend.md) — A `status-legend` is an inline key mapping a status colour to its meaning. [#feedback](../sample-athletics-ui-kitchen-sink.html#feedback)
* [stepper](components/stepper.md) — A `stepper` shows progress through an ordered, multi-step flow. [#workflow](../sample-athletics-ui-kitchen-sink.html#workflow)
* [tag-input](components/tag-input.md) — A `tag-input` is a field that holds removable chips plus a free-text entry. [#inputs](../sample-athletics-ui-kitchen-sink.html#inputs)
* [time-change-badge](components/time-change-badge.md) — A `time-change-badge` shows a rescheduled time as old → new with the delta. [#buttons](../sample-athletics-ui-kitchen-sink.html#buttons)
* [toast-region](components/toast-region.md) — A `toast-region` is the app-shell live region that shows transient command feedback after a successful or recoverable action. [#overlays](../sample-athletics-ui-kitchen-sink.html#overlays)
* [tooltip](components/tooltip.md) — A `tooltip` reveals a short explanatory string on hover/focus of a dotted-underline term. [#overlays](../sample-athletics-ui-kitchen-sink.html#overlays)
* [type-chip](components/type-chip.md) — A `type-chip` is a compact pill marking a record's category (e.g. Athlete / Staff) in a dense table cell. [#buttons](../sample-athletics-ui-kitchen-sink.html#buttons)
* [vertical-timeline](components/vertical-timeline.md) — A `vertical-timeline` is a top-to-bottom list of events on a single connecting rail. [#workflow](../sample-athletics-ui-kitchen-sink.html#workflow)
